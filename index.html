Employee Attrition Analysis

Business problem

Identify the main workforce patterns associated with employee attrition and provide management with actionable analytical insights.

Analysis

  • Data cleaning and exploratory analysis in Python.
  • SQL-based analytical validation.
  • Attrition analysis across demographic and job factors.
  • Power BI dashboard development.

Customer Analytics

Customer Segmentation

GitHub ↗

Customer behavior and RFM segmentation analysis using more than one million UK e-commerce transaction lines to identify high-value customer groups.

1.07M+ Transaction lines
63.2% Revenue from top 10%
21.9% Champions customers
Python Pandas SQL Power BI
View analysis +

Business problem

Understand customer value and purchasing behavior and identify segments that can support more targeted commercial decisions.

Analysis

  • Transaction data cleaning and preparation.
  • Exploratory customer behavior analysis.
  • RFM scoring and customer segmentation.
  • SQL validation using DuckDB.
  • Power BI reporting structure.

Key findings

  • The top 10% of customers generated 63.2% of net revenue.
  • The top 1% generated 31.1% of net revenue.
  • Champions represented 21.9% of customers while contributing 69.3% of revenue.
